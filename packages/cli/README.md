# @rylease/cli

The `rylease` command: run a release, write change files, and test release workflows locally with `rylease test`. See [rylease's docs](https://github.com/ryangarber/rylease/blob/main/docs/cli.md).

`rylease` itself runs this package, so either works:

```sh
npx rylease test
npx @rylease/cli test
```
